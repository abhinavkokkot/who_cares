### Project Description

Rate Hooman is a playful social experiment where people discover humans from their college community and give them completely unnecessary ratings.

Users can create a profile, capture a selfie, choose funny human titles, rate Aura, answer ridiculous scenario questions, and leave manual reviews.

### The Problem (that doesn't exist)

People have no reliable way to know whether their friends would survive a zombie apocalypse, press a “DO NOT PRESS” button, or become broke after receiving one million dollars.

### The Solution (that nobody asked for)

Rate Hooman turns these urgent non-problems into sliders, emoji titles, profile statistics, manual reviews, and dramatic coin-flip review appeals.

## Technical Details

### Technologies/Components Used

For Software:

- JavaScript
- React 19
- Vite
- CSS
- Browser MediaDevices API for selfie capture
- Git and GitHub

For Hardware:

- No special hardware required
- A webcam or phone camera is useful for selfie capture

### Implementation

The current project is a frontend prototype. It includes:

- Landing page and onboarding flow
- Signup and login screens
- College, course, semester, age, height, and weight fields
- Browser camera selfie capture for the profile picture
- Home feed with college/community profiles
- Search and filters
- Manual Aura slider from `-10` to `+100`
- Emoji-based human titles
- Most-voted title display
- Six scenario ratings using `0–5` manual sliders
- Manual review writing
- Owner-only, one-time review appeals
- Coin-flip appeal decisions
- Approved appeals delete the review
- Public profile details
- Ratings received and ratings given tabs
